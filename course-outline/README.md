## 📅 Day-by-Day Breakdown

### Module 01 — Digital Foundations

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 01 | Understanding computers, operating systems & file management | Hardware vs software, OS types, file systems, folders |
| 02 | The internet, browsers, email & online safety | How the internet works, browser tools, email, passwords, phishing |
| 03 | Cloud tools — Google Drive, Gmail, productivity apps | Cloud storage, Google Workspace, collaboration, digital organisation |

### Module 02 — Tools of the Trade

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 01 | Setting up VS Code, terminal basics & folder structures | IDE installation, extensions, terminal commands, project folders |
| 02 | Git & GitHub — version control from scratch | Repositories, commits, branches, push/pull, GitHub workflow |
| 03 | Markdown, documentation & how to use README files | Markdown syntax, writing READMEs, documentation best practices |

### Module 03 — Web Fundamentals: HTML

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 01 | What is HTML? Structure, tags & your first webpage | HTML boilerplate, elements, tags, attributes, browser rendering |
| 02 | Text, links, images & lists | Headings, paragraphs, anchors, image embedding, ordered/unordered lists |
| 03 | Tables, forms & inputs | Table structure, form elements, input types, labels, buttons |
| 04 | Semantic HTML5 & accessibility best practices | Semantic elements, ARIA, alt text, screen readers, web accessibility |

### Module 04 — Web Styling: CSS

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 01 | CSS basics — selectors, properties & the box model | Inline/internal/external CSS, selectors, box model, margin/padding |
| 02 | Colours, typography & the visual hierarchy | Colour systems, fonts, Google Fonts, font stacks, visual weight |
| 03 | Flexbox — modern layouts made simple | Flex container, flex items, alignment, wrapping, common patterns |
| 04 | CSS Grid — two-dimensional layouts | Grid container, rows/columns, template areas, gap, responsive grids |
| 05 | Responsive design & media queries | Viewport, breakpoints, mobile-first, media queries, responsive images |

### Module 05 — Frontend Interactivity: JavaScript

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 01 | JS syntax, variables, data types & operators | Variables (let/const), strings, numbers, booleans, arithmetic, comparison |
| 02 | Functions, conditionals & loops | Function declarations/expressions, if/else, switch, for/while loops |
| 03 | DOM manipulation — making pages interactive | document.querySelector, innerHTML, classList, creating/removing elements |
| 04 | Events, forms & user input handling | addEventListener, event objects, form validation, preventing defaults |
| 05 | Fetch API & working with JSON data | HTTP requests, fetch(), .then()/.catch(), async/await, parsing JSON |

### Module 06 — Frontend Mastery

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 01 | Introduction to React — components & props | What is React, JSX, functional components, passing props |
| 02 | State, hooks & interactivity in React | useState, useEffect, handling events in React, re-rendering |
| 03 | Routing, project structure & best practices | React Router, folder structure, component naming, code organisation |
| 04 | Build & deploy your first React app | Build process, environment variables, Netlify/Vercel deployment |

### Module 07 — Backend Basics: Node.js & APIs

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 01 | How the web works — servers, HTTP & REST APIs | Client-server model, HTTP methods, status codes, REST principles |
| 02 | Node.js & Express — setting up a backend | Node runtime, npm, Express server, routes, request/response |
| 03 | Routes, middleware & handling requests | Route parameters, query strings, middleware chain, error handling |
| 04 | Connecting to a database (MongoDB/Firebase intro) | Database connection, CRUD operations, environment configuration |

### Module 08 — Databases & Data Thinking

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 01 | Database concepts — SQL vs NoSQL | What is a database, relational vs document, when to use each |
| 02 | SQL fundamentals — queries, joins & schemas | SELECT, INSERT, UPDATE, DELETE, JOINs, primary/foreign keys |
| 03 | MongoDB basics & data modeling | Documents, collections, CRUD in Mongo, schema design, embedding vs referencing |

### Module 09 — Deployment, DevOps & Professional Workflow

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 01 | Domain names, hosting & deploying websites | DNS, shared/cloud hosting, static site deployment, custom domains |
| 02 | Environment variables, secrets & .env files | Why secrets matter, .env files, dotenv, never commit secrets |
| 03 | CI/CD pipelines — automated testing & deployment | What is CI/CD, GitHub Actions basics, automated tests, auto-deploy |
| 04 | Developer workflow — Agile, tickets, code reviews & collaboration | Agile methodology, sprint planning, pull request reviews, pair programming |

### Module 10 — Career Launch & Monetisation

| Day | Topic | Key Concepts |
|-----|-------|-------------|
| 01 | Building your developer portfolio — GitHub & personal site | Portfolio content, GitHub profile README, project showcase |
| 02 | Writing a winning tech CV & LinkedIn profile | CV structure, keywords, LinkedIn optimisation, personal branding |
| 03 | Freelancing, remote work & finding your first client | Freelance platforms, proposals, pricing, client management |
| 04 | How to keep learning — roadmaps, communities & staying current | Learning roadmaps, developer communities, conferences, staying motivated |

### Task 5: Full README

```markdown
# Weather Buddy 🌤️

A simple, beginner-friendly weather app that shows current weather conditions for any city in the world.

## Features

- 🔍 Search weather by city name
- 🌡️ Display temperature, humidity, and wind speed
- 🎨 Clean, responsive design
- 📱 Works on desktop and mobile
- ⭐ Save favourite cities

## Screenshots

![Home Screen](screenshots/home.png)
![Search Results](screenshots/results.png)

## Technologies Used

| Technology | Purpose |
|-----------|---------|
| HTML5 | Page structure |
| CSS3 | Styling & layout |
| JavaScript | Logic & API calls |
| OpenWeather API | Weather data |

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourname/weather-buddy.git
   ```
2. Navigate to the project folder:
   ```bash
   cd weather-buddy
   ```
3. Open `index.html` in your browser:
   ```bash
   open index.html
   ```

No build tools or servers required — it's a static site!

## Contributing

Contributions are welcome! Please:
1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Commit your changes: `git commit -m "Add your feature"`
4. Push to the branch: `git push origin feature/your-feature`
5. Open a Pull Request

## License

This project is licensed under the MIT License. See [LICENSE](LICENSE) for details.
```

> 💡 **Key takeaway:** A well-structured README makes the difference between a project that people use and one that gets ignored. Take time to write good documentation — it's a superpower that most beginners overlook.

# 🛠️ Module 02 — Tools of the Trade

![Level: Beginner](https://img.shields.io/badge/Level-Beginner-brightgreen) ![Days: 3](https://img.shields.io/badge/Days-3-blue)

> Every developer's essential toolkit — set up before writing a single line of code.

---

## 🎯 By the End of This Module You Will Be Able To:

1. Install and configure VS Code with essential extensions for web development
2. Navigate the terminal/command line to create folders, move files, and run commands
3. Understand what version control is and why every developer uses it
4. Use Git to track changes — init, add, commit, branch, merge
5. Push code to GitHub, create repositories, and write professional README files using Markdown

# 🚀 Module 06 — Frontend Mastery

![Level: Intermediate](https://img.shields.io/badge/Level-Intermediate-yellow) ![Days: 4](https://img.shields.io/badge/Days-4-blue)

> Level up. Modern frontend workflows and a real project.

---

## 🎯 By the End of This Module You Will Be Able To:

1. Understand what React is, why it exists, and how component-based architecture works
2. Build functional React components, pass data using props, and compose a UI from reusable parts
3. Manage state with `useState`, handle side effects with `useEffect`, and build interactive UIs
4. Set up routing with React Router, organise a scalable project structure, and follow best practices
5. Build and deploy a complete React application to Netlify or Vercel

---

| Day | Topic | Key Concepts | Exercise |
|-----|-------|-------------|----------|
| [Day 01](day-01/) | Introduction to React — components & props | What is React, JSX, functional components, passing props | Build a profile card component |
| [Day 02](day-02/) | State, hooks & interactivity in React | useState, useEffect, handling events in React, re-rendering | Build a counter & toggle app |
| [Day 03](day-03/) | Routing, project structure & best practices | React Router, folder structure, component naming, code organisation | Add multi-page navigation |
| [Day 04](day-04/) | Build & deploy your first React app | Build process, environment variables, Netlify/Vercel deployment | Deploy your React app live |

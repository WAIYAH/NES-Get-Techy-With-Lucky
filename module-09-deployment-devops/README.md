# 🚢 Module 09 — Deployment, DevOps & Professional Workflow

![Level: Advanced](https://img.shields.io/badge/Level-Advanced-red) ![Days: 4](https://img.shields.io/badge/Days-4-blue)

> Ship real products. Work like a professional developer.

---

## 🎯 By the End of This Module You Will Be Able To:

1. Register a domain name, choose a hosting provider, and deploy a website to the live internet
2. Use environment variables and `.env` files to manage secrets securely — and never commit them
3. Set up a basic CI/CD pipeline using GitHub Actions — automated testing and deployment on every push
4. Work in a professional developer workflow — Agile sprints, tickets, code reviews, and collaboration
5. Understand the full journey from code on your laptop to a live product used by real people

---

## 📅 Day-by-Day Breakdown

| Day | Topic | Key Concepts | Exercise |
|-----|-------|-------------|----------|
| [Day 01](day-01/) | Domain names, hosting & deploying websites | DNS, shared/cloud hosting, static site deployment, custom domains | Deploy a site to Netlify with a custom domain |
| [Day 02](day-02/) | Environment variables, secrets & .env files | Why secrets matter, .env files, dotenv, never commit secrets | Secure an API key using .env |
| [Day 03](day-03/) | CI/CD pipelines — automated testing & deployment | What is CI/CD, GitHub Actions basics, automated tests, auto-deploy | Set up a GitHub Actions workflow |
| [Day 04](day-04/) | Developer workflow — Agile, tickets, code reviews & collaboration | Agile methodology, sprint planning, pull request reviews, pair programming | Simulate a sprint with GitHub Issues & PRs |

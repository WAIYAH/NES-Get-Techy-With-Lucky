# 🎨 Module 04 — Web Styling: CSS

![Level: Intermediate](https://img.shields.io/badge/Level-Intermediate-yellow) ![Days: 5](https://img.shields.io/badge/Days-5-blue)

> Make things beautiful. From box model to layout mastery.

---

## 🎯 By the End of This Module You Will Be Able To:

1. Write CSS using selectors, properties, and the box model to control spacing and sizing
2. Apply colours, typography, and visual hierarchy to make pages look professional
3. Build modern layouts using Flexbox — align, distribute, and wrap elements effortlessly
4. Create two-dimensional layouts with CSS Grid — rows, columns, and template areas
5. Make any website responsive using media queries and mobile-first design principles

---

## 📅 Day-by-Day Breakdown

| Day | Topic | Key Concepts | Exercise |
|-----|-------|-------------|----------|
| [Day 01](day-01/) | CSS basics — selectors, properties & the box model | Inline/internal/external CSS, selectors, box model, margin/padding | Style your first webpage |
| [Day 02](day-02/) | Colours, typography & the visual hierarchy | Colour systems, fonts, Google Fonts, font stacks, visual weight | Design a styled blog page |
| [Day 03](day-03/) | Flexbox — modern layouts made simple | Flex container, flex items, alignment, wrapping, common patterns | Build a navigation bar & card layout |
| [Day 04](day-04/) | CSS Grid — two-dimensional layouts | Grid container, rows/columns, template areas, gap, responsive grids | Create a photo gallery grid |
| [Day 05](day-05/) | Responsive design & media queries | Viewport, breakpoints, mobile-first, media queries, responsive images | Make a page fully responsive |

# 🖥️ Module 01 — Digital Foundations

![Level: Beginner](https://img.shields.io/badge/Level-Beginner-brightgreen) ![Days: 3](https://img.shields.io/badge/Days-3-blue)

> Who is a computer for? Files, folders, OS basics, browsers, the internet.

---

## 🎯 By the End of This Module You Will Be Able To:

1. Understand what a computer is, how it works, and confidently navigate an operating system
2. Manage files and folders — create, move, rename, organise, and find anything on your machine
3. Explain how the internet works and use a browser like a power user
4. Set up and use email safely, recognise phishing, and practice good digital hygiene
5. Use cloud tools like Google Drive and Google Docs to store, share, and collaborate on files

## 📋 Prerequisites

**None.** This is where everyone starts. No prior tech knowledge required.

---

## 🛠️ Tools & Software Needed

- A computer (Windows, Mac, or Linux — any will work)
- An internet connection
- A web browser (Chrome recommended)
- A Google account (free)

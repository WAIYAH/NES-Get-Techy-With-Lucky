## 📖 Lesson Content

### What Is a Computer?

A computer is a machine that takes **input** (what you give it), **processes** it (does something with it), and produces **output** (gives you a result).

That's it. Everything else — the apps, the internet, the games — is built on top of that simple idea.

**Real-world example:** You type a message (input) → the computer processes it → the message appears on screen (output).

### Hardware vs Software

| Hardware | Software |
|----------|----------|
| The **physical parts** you can touch | The **programs and instructions** that run on the hardware |
| Keyboard, mouse, screen, hard drive, RAM, CPU | Windows, Chrome, Microsoft Word, WhatsApp |
| Think of it as the **body** | Think of it as the **brain and skills** |

**Key hardware components to know:**

- **CPU (Central Processing Unit)** — the "brain" that does all the thinking
- **RAM (Random Access Memory)** — short-term memory for things you're currently doing
- **Hard Drive / SSD** — long-term storage for all your files
- **Monitor** — the screen that shows you output
- **Keyboard & Mouse** — your main input devices

### What Is an Operating System (OS)?

An operating system is the **software that manages everything** on your computer. It's the bridge between you and the hardware.

Without an OS, you'd have no desktop, no Start menu, no way to open files — just a blank machine.

**The big three:**

| OS | Who uses it | Look & feel |
|----|------------|-------------|
| **Windows** | Most PCs worldwide | Start menu, taskbar, File Explorer |
| **macOS** | Apple Mac computers | Dock, Finder, Mission Control |
| **Linux** | Developers, servers | Terminal-heavy, highly customisable |

> 💡 **Fun fact:** Your phone also has an OS — Android (based on Linux) or iOS (based on macOS).

### Files, Folders & the File System

Everything on your computer is stored as a **file**. Files live inside **folders** (also called directories). Folders can contain other folders — creating a tree-like structure.

```
My Computer/
├── Documents/
│   ├── School/
│   │   ├── assignment.docx
│   │   └── notes.pdf
│   └── Personal/
│       └── budget.xlsx
├── Pictures/
│   └── holiday.jpg
└── Downloads/
    └── installer.exe
```

### File Extensions — What Do They Mean?

The letters after the dot (`.`) in a filename tell your computer what **type** of file it is:

| Extension | Type | Opens with |
|-----------|------|-----------|
| `.docx` | Word document | Microsoft Word, Google Docs |
| `.pdf` | Portable document | Any PDF reader |
| `.jpg` / `.png` | Image | Photo viewer, browser |
| `.mp3` / `.mp4` | Audio / Video | Media player |
| `.html` | Web page | Browser |
| `.txt` | Plain text | Notepad, any text editor |

### Best Practices for File Management

1. **Name files clearly** — `project-report-final.docx` not `asdfg.docx`
2. **Use folders** — don't dump everything on the Desktop
3. **No special characters** — avoid `? * : " < > |` in file names
4. **Use hyphens or underscores** — `my-file-name.txt` or `my_file_name.txt`
5. **Back up important files** — use a USB drive or cloud storage

## ✅ Step-by-Step Tasks

1. **Identify your OS** — Right-click "This PC" (Windows) or click the Apple logo → "About This Mac" (Mac). Write down which OS and version you're using.

2. **Explore your file system** — Open File Explorer (Windows) or Finder (Mac). Navigate to your Documents folder. How many folders are inside?

3. **Create a project folder structure** — Create the following folder structure on your computer:
   ```
   GetTechyWithLucky/
   ├── Module-01/
   │   ├── notes/
   │   └── exercises/
   ├── Module-02/
   └── projects/
   ```

4. **Create and rename files** — Inside `Module-01/notes/`, create a new text file called `day-01-notes.txt`. Open it and write three things you learned today. Save it.

5. **Move a file** — Download any image from the internet. Move it from your Downloads folder into `GetTechyWithLucky/projects/`.

## 🐛 Common Mistakes to Avoid

1. **Saving everything to the Desktop** — It gets cluttered fast and makes files hard to find. Always use organised folders.
2. **Using spaces and special characters in file names** — Some systems and programming tools don't handle them well. Use hyphens (`-`) or underscores (`_`) instead.
3. **Not knowing where your files are saved** — Always check the save location before clicking "Save". Many people lose files because they saved them in an unexpected folder.

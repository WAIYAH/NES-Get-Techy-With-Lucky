### Task 2: Create a Google Doc (Example)

**Document content:**

# My Get Techy with Lucky — Module 01 Notes

## Key Takeaways
- Computers work on a simple input → process → output model, and everything we see is built on top of that
- The internet is just computers sending files to each other — a browser makes HTTP requests to servers which send back HTML, CSS, and JavaScript
- Cloud storage lets me access my files from anywhere and collaborate in real-time, which is far more flexible than keeping everything on one device

## Local vs Cloud Storage

| Feature | Local Storage | Cloud Storage |
|---------|--------------|---------------|
| Where files are stored | On my computer's hard drive | On remote servers (data centres) |
| Accessibility | Only from this device | Any device with internet |
| Collaboration | Difficult — need to send files back and forth | Easy — share a link and edit together |
| Backup | Manual — I must remember to do it | Automatic — saves continuously |
| Cost | One-time purchase for hardware | Free tier available (15GB on Google Drive) |

### Task 5: Explore Version History

- **How many versions saved?** 5 (will vary — one for each major edit/save point)
- **First version time?** 10:23 AM (will vary — when you first created the doc)
- **Can you restore a previous version?** Yes — click on any previous version → "Restore this version". Google keeps a full history of every change.

> 💡 **Pro tip:** You can also name versions! Click the three dots next to any version → "Name this version". Great for marking milestones like "Before major edits" or "Final draft".

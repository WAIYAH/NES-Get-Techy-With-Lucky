## 📖 Lesson Content

### What Is "the Cloud"?

When people say "the cloud", they just mean **someone else's computer**. Seriously.

Cloud computing means storing and accessing files, apps, and services over the **internet** instead of on your own computer's hard drive.

**Why use the cloud?**
- 📂 **Access files anywhere** — laptop at home, phone on the bus, library computer
- 🔄 **Automatic backups** — your files are saved even if your computer breaks
- 👥 **Collaboration** — multiple people can edit the same document at the same time
- 💾 **Free storage** — Google Drive gives you 15GB free

### Cloud vs Local Storage

| Feature | Local Storage | Cloud Storage |
|---------|--------------|---------------|
| **Where files live** | On your hard drive | On a remote server |
| **Access** | Only from that device | From any device with internet |
| **Backup** | You must back up manually | Automatic |
| **Sharing** | Email attachments, USB drives | Share with a link |
| **Speed** | Instant access | Depends on internet speed |
| **Cost** | One-time (buy a drive) | Free tier + paid plans |

### Popular Cloud Storage Services

| Service | Free Storage | Best For |
|---------|-------------|----------|
| **Google Drive** | 15 GB | Google ecosystem, collaboration |
| **OneDrive** | 5 GB | Windows & Microsoft 365 users |
| **Dropbox** | 2 GB | Simple file syncing |
| **iCloud** | 5 GB | Apple devices |
| **MEGA** | 20 GB | Large free storage |

> 💡 **We'll focus on Google Drive** because it's free, generous with storage, and tightly integrated with powerful productivity tools.

### Getting Started with Google Drive

**Step 1: Access Google Drive**
1. Go to [drive.google.com](https://drive.google.com)
2. Sign in with your Google account (create one if you don't have one)
3. You'll see your Drive — currently probably empty or with a few files

**Step 2: Understand the interface**

```
┌──────────────────────────────────────────────────┐
│  🔍 Search in Drive                              │
├──────────┬───────────────────────────────────────┤
│  + New   │   My Drive                            │
│          │   ┌──────┐ ┌──────┐ ┌──────┐         │
│ My Drive │   │ 📁   │ │ 📁   │ │ 📄   │         │
│ Shared   │   │Folder│ │Folder│ │ File │         │
│ Recent   │   └──────┘ └──────┘ └──────┘         │
│ Starred  │                                       │
│ Trash    │                                       │
├──────────┴───────────────────────────────────────┤
│  Storage: 0.1 GB of 15 GB used                   │
└──────────────────────────────────────────────────┘
```

**Key areas:**
- **My Drive** — your personal files
- **Shared with me** — files others have given you access to
- **Recent** — files you've opened recently
- **Starred** — files you've marked as important
- **Trash** — deleted files (emptied after 30 days)

### Creating Files in Google Drive

Click **"+ New"** to create:

| Option | What It Creates | Similar To |
|--------|----------------|-----------|
| **Google Docs** | A text document | Microsoft Word |
| **Google Sheets** | A spreadsheet | Microsoft Excel |
| **Google Slides** | A presentation | Microsoft PowerPoint |
| **Google Forms** | A survey or quiz | SurveyMonkey |
| **Folder** | A new folder | File Explorer folder |

### Google Docs — Your Free Word Processor

Google Docs is a **free, online alternative to Microsoft Word**. Key features:

- **Auto-save** — it saves every few seconds. No more losing work!
- **Real-time collaboration** — invite someone and watch them type live
- **Version history** — see every change ever made (File → Version history)
- **Comments** — highlight text and add a comment for feedback
- **Export** — download as .docx, .pdf, .txt, or other formats

**Formatting essentials:**
- Use **Heading 1** for titles, **Heading 2** for sections, **Heading 3** for sub-sections
- Bold = `Ctrl + B`, Italic = `Ctrl + I`, Underline = `Ctrl + U`
- Insert links = `Ctrl + K`
- Find text = `Ctrl + F`

### Sharing & Collaboration

This is where Google Drive truly shines. You can share files with specific permissions:

| Permission | What They Can Do |
|-----------|-----------------|
| **Viewer** | Can only look at the file |
| **Commenter** | Can view and add comments, but not edit |
| **Editor** | Can make changes to the file |

**How to share:**
1. Right-click a file → **"Share"**
2. Enter the person's email address
3. Choose their permission level
4. Click **"Send"**

**Or share with a link:**
1. Click **"Share"** → **"Copy link"**
2. Set access to "Anyone with the link"
3. Choose permission (Viewer/Commenter/Editor)
4. Send the link via email, chat, etc.

> ⚠️ **Be careful with "Anyone with the link"** — anyone who gets that link can access the file. For sensitive documents, share with specific email addresses only.

### Organising Your Google Drive

Keep your Drive tidy from day one:

```
My Drive/
├── 📁 GetTechyWithLucky/
│   ├── 📁 Module-01/
│   ├── 📁 Module-02/
│   └── 📁 Projects/
├── 📁 Work/
│   ├── 📁 Documents/
│   └── 📁 Presentations/
├── 📁 Personal/
└── 📁 Templates/
```

**Pro tips:**
- Use **colour-coded folders** (right-click a folder → "Organise" → pick a colour)
- **Star** important files for quick access
- Use **search** — Google's search is incredibly powerful, even inside documents
- **Don't duplicate** — share files instead of making copies

## 🐛 Common Mistakes to Avoid

1. **Not organising files from the start** — It's easy to dump everything in the root of "My Drive" and think you'll sort it later. You won't. Create folders from day one.
2. **Sharing with "Anyone with the link" for sensitive files** — This is fine for things like study notes. But for anything personal or professional, share with specific email addresses and set appropriate permissions.
3. **Forgetting that cloud files need internet** — If you're going somewhere without internet, use Google Drive's "Make available offline" feature to download files in advance.

## Exercise 2: Proposals — Example

### Job Post 1

**Job Title:** Build a booking system for a hair salon
**Key Requirements:** Calendar view, time slot selection, SMS notifications, admin dashboard

**Proposal:**
```
Hi [Client Name],

Your salon booking system sounds like a great project — I've built 
similar appointment scheduling tools before. Here's a recent one I 
completed: [portfolio link].

Here's how I'd approach this:

Week 1: Design the database schema and booking flow UI (calendar + 
time slots). I'll share mockups for your approval before coding.

Week 2: Build the frontend — calendar view, slot selection, booking 
confirmation page. React with Tailwind CSS for a clean, mobile-friendly 
design.

Week 3: Backend API — Express + MongoDB for managing bookings, staff 
schedules, and the admin dashboard. Integrate an SMS API (Twilio or 
Africa's Talking) for appointment reminders.

Week 4: Testing, your feedback revisions, and deployment. I'll deploy 
and hand over full documentation.

Estimated cost: $XXX (fixed price, includes 2 rounds of revisions).
Timeline: 4 weeks.

Happy to jump on a 15-minute call to discuss the details. When works 
best for you?

Best,
[Your Name]
```

you'd want — no obligation at all.

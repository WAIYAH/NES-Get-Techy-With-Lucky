## Exercise 2: 6-Month Roadmap — Example (Full-Stack Path)

### Month 1: TypeScript Fundamentals
- **Topic:** TypeScript basics, types, interfaces, generics
- **Resource:** [TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/) + [Matt Pocock's Total TypeScript (free)](https://www.totaltypescript.com/)
- **Mini-project:** Refactor portfolio site's JavaScript to TypeScript

### Month 2: Next.js & Server-Side Rendering
- **Topic:** Next.js pages, server components, API routes, dynamic routing
- **Resource:** [Next.js Official Tutorial](https://nextjs.org/learn)
- **Mini-project:** Build a blog with Next.js using MDX files for posts

### Month 3: Advanced Backend — Auth & File Handling
- **Topic:** JWT authentication, bcrypt, file uploads (multer), session management
- **Resource:** [The Odin Project — Node.js Path](https://www.theodinproject.com/paths/full-stack-javascript/courses/nodejs)
- **Mini-project:** Build a user auth system with registration, login, and profile picture upload

### Month 4: PostgreSQL & Prisma ORM
- **Topic:** Relational databases, SQL queries, Prisma schema, migrations
- **Resource:** [Prisma Docs — Getting Started](https://www.prisma.io/docs/getting-started)
- **Mini-project:** Build a task management app with PostgreSQL, Prisma, and Express

### Month 5: Testing — Jest & React Testing Library
- **Topic:** Unit tests, integration tests, mocking, test-driven development
- **Resource:** [Testing JavaScript — Kent C. Dodds](https://testingjavascript.com/) (or free YouTube tutorials)
- **Mini-project:** Add comprehensive tests to the task management app from Month 4

### Month 6: System Design & Capstone
- **Topic:** System design basics, architecture patterns, performance optimisation
- **Resource:** [System Design Primer — GitHub](https://github.com/donnemartin/system-design-primer)
- **Capstone project:** Build a full-stack SaaS app (e.g., invoice generator, project management tool) with Next.js, PostgreSQL, auth, testing, and CI/CD

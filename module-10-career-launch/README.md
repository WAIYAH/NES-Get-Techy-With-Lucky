# 🎯 Module 10 — Career Launch & Monetisation

![Level: Advanced](https://img.shields.io/badge/Level-Advanced-red) ![Days: 4](https://img.shields.io/badge/Days-4-blue)

> Land the job. Build the brand. Make money from your skills.

---

## 🎯 By the End of This Module You Will Be Able To:

1. Build a professional developer portfolio — both a GitHub profile README and a personal portfolio website
2. Write a compelling tech CV and optimise your LinkedIn profile to attract recruiters
3. Set up freelancing profiles, write winning proposals, price your services, and land your first client
4. Create a personal learning roadmap, join developer communities, and stay current in a fast-changing field
5. Understand multiple income streams as a developer — employment, freelancing, teaching, and digital products

## 📖 Lesson Content

### Why Your CV Matters

Most tech companies receive hundreds of applications per role. Your CV gets about **6–10 seconds** of initial screening. If it doesn't immediately show relevance, it's rejected.

Two screenings happen:
1. **ATS (Applicant Tracking System)** — Software scans for keywords
2. **Human reviewer** — Recruiter or hiring manager skims for fit

Your CV must pass both.

### CV Structure for Developers

```
┌─────────────────────────────────────┐
│  NAME & CONTACT INFO                │
│  Email · Phone · LinkedIn · GitHub  │
│  Portfolio URL                      │
├─────────────────────────────────────┤
│  PROFESSIONAL SUMMARY (2-3 lines)  │
├─────────────────────────────────────┤
│  TECHNICAL SKILLS                   │
│  Languages · Frameworks · Tools     │
├─────────────────────────────────────┤
│  PROJECTS (2-3 with descriptions)  │
├─────────────────────────────────────┤
│  EXPERIENCE (if any)               │
├─────────────────────────────────────┤
│  EDUCATION                         │
├─────────────────────────────────────┤
│  CERTIFICATIONS / EXTRAS           │
└─────────────────────────────────────┘
```

### Writing a Professional Summary

Your summary is your elevator pitch. Keep it to 2–3 lines.

**Bad:**
> I am a hard-working and passionate individual looking for an opportunity to learn and grow.

**Good:**
> Junior full-stack developer with hands-on experience building responsive web applications using React, Node.js, and MongoDB. Built and deployed 5+ projects including an e-commerce platform and portfolio site. Strong foundation in Git workflows, API design, and agile development.

### Technical Skills Section

List skills the job description mentions. Organise by category:

```
Languages:    JavaScript, Python, HTML, CSS, SQL
Frameworks:   React, Express, Node.js, Tailwind CSS
Databases:    MongoDB, PostgreSQL
Tools:        Git, GitHub, VS Code, Postman, Figma
Deployment:   Netlify, Vercel, Render, GitHub Actions
```

> **Tip:** Mirror the job description's wording. If they say "React.js", write "React.js" not just "React".

### Writing Project Descriptions

Projects are the most important section for junior developers. Use this format:

```
PROJECT NAME | Live Link | GitHub Repo
Technologies: React, Express, MongoDB, Tailwind CSS

- Built a full-stack e-commerce platform with product listings, cart, 
  and checkout flow serving 50+ demo products
- Implemented user authentication using JWT tokens and bcrypt password hashing
- Deployed frontend to Netlify and backend to Render with CI/CD via GitHub Actions
```

#### The STAR Method for Bullet Points

| Letter | Meaning | Example |
|--------|---------|---------|
| **S** | Situation | "For a client's restaurant website..." |
| **T** | Task | "...needed to reduce page load time..." |
| **A** | Action | "...optimised images, implemented lazy loading, and migrated to Vite..." |
| **R** | Result | "...reducing load time from 4.2s to 1.1s" |

**Weak bullet:** "Worked on the frontend"

**Strong bullet:** "Built a responsive React dashboard with 8 interactive data visualisation components, reducing manual reporting time by 3 hours per week"

### Experience Section

Even non-tech jobs show transferable skills:

```
CUSTOMER SERVICE REPRESENTATIVE — Safaricom | 2022–2023
- Resolved 40+ customer queries daily, developing strong problem-solving 
  and communication skills
- Created Excel templates that automated weekly reporting, saving 2 hours per week
- Trained 3 new team members on internal systems and processes
```

### LinkedIn Optimisation

#### Profile Checklist

- [ ] **Professional photo** — Clear face, good lighting, plain background
- [ ] **Headline** — Not just your job title. Example: "Full-Stack Developer | React · Node.js · MongoDB | Building solutions for African startups"
- [ ] **About section** — 3-4 paragraphs: who you are, what you do, what you're looking for
- [ ] **Experience** — Mirror your CV, add media (screenshots, links)
- [ ] **Skills** — Add 15+ relevant skills. Ask connections to endorse them
- [ ] **Featured** — Pin your best project links and portfolio
- [ ] **Custom URL** — linkedin.com/in/yourname (not random numbers)

#### LinkedIn Posts That Get Noticed

```
✅ "Just deployed my first full-stack project! Built with React and 
    Node.js. Here's what I learned about authentication..."
    
✅ "I just completed a 39-day coding bootcamp. Here are my top 5 
    takeaways for anyone starting their coding journey..."

❌ "Looking for a job. Please help." (Low engagement, no value)
```

### Personal Branding — Consistency

Ensure your name, photo, and messaging are consistent across:

| Platform | Purpose |
|----------|---------|
| **GitHub** | Code portfolio — clean repos, profile README |
| **LinkedIn** | Professional networking — recruiters find you here |
| **Portfolio site** | Visual showcase — your best work, designed your way |
| **Twitter/X** | Tech community — share learnings, engage with devs |

## ✅ Step-by-Step Tasks

1. **Write your CV** — Create a one-page developer CV using the structure above. Include a professional summary, tech skills, 2–3 projects with impact-driven bullet points, and education.

2. **Optimise your LinkedIn** — Update your headline, about section, and experience. Add your projects to the Featured section with links.

3. **Write 3 STAR bullet points** — For your best project, write 3 bullet points following the STAR method. Focus on what you built, what tech you used, and what the result was.

4. **Peer review** — Share your CV with a partner or peer. Give each other feedback on clarity, impact, and formatting.

5. **Create a "master CV"** — Keep a long version with ALL projects and experience. For each application, create a tailored one-page version highlighting the most relevant items.

## 🐛 Common Mistakes to Avoid

1. **Using fancy formatting** — ATS systems can't read tables, columns, graphics, or unusual fonts. Use a simple, single-column layout with standard headings. Save visual flair for your portfolio site.
2. **Listing responsibilities instead of achievements** — "Responsible for frontend development" says nothing. "Built a React dashboard that reduced reporting time by 3 hours/week" shows impact.
3. **One generic CV for every application** — Tailor your CV to each job. Move relevant skills and projects to the top. Mirror the job description's keywords.

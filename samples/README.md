# 📁 Sample Projects

This folder contains reference portfolio projects that students can study and learn from.

## Projects

### Kcau-Ajira-Portfolio

A complete multi-page portfolio website with:
- Responsive design with Tailwind CSS
- Multiple pages (Home, About, Skills, Programs, Contact, etc.)
- JavaScript animations, countdown timer, and form handling
- Legal pages (Privacy Policy, Terms of Service, Code of Conduct)
- Resource pages (AI Tools, Job Board, Learning Materials, etc.)

**Preview:** Open `kcau-ajira-portfolio/index.html` in your browser.

### Portfolio One

A single-page modern portfolio template.

**Preview:** Open `portfolio-one/index.html` in your browser.

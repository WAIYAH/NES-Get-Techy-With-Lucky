# ⚡ Module 05 — Frontend Interactivity: JavaScript

![Level: Intermediate](https://img.shields.io/badge/Level-Intermediate-yellow) ![Days: 5](https://img.shields.io/badge/Days-5-blue)

> Bring pages to life. Core JS every developer must know.

---

## 🎯 By the End of This Module You Will Be Able To:

1. Write JavaScript using variables, data types, operators, and understand how JS runs in the browser
2. Use functions, conditionals, and loops to control program flow and solve problems
3. Manipulate the DOM — select elements, change content, add/remove classes, and create elements dynamically
4. Handle user events — clicks, form submissions, keyboard input — and validate form data
5. Fetch data from external APIs using the Fetch API and display JSON data on a page

---

## 📅 Day-by-Day Breakdown

| Day | Topic | Key Concepts | Exercise |
|-----|-------|-------------|----------|
| [Day 01](day-01/) | JS syntax, variables, data types & operators | Variables (let/const), strings, numbers, booleans, arithmetic, comparison | Build a simple calculator |
| [Day 02](day-02/) | Functions, conditionals & loops | Function declarations/expressions, if/else, switch, for/while loops | Create a grade checker |
| [Day 03](day-03/) | DOM manipulation — making pages interactive | document.querySelector, innerHTML, classList, creating/removing elements | Build a dynamic to-do list |
| [Day 04](day-04/) | Events, forms & user input handling | addEventListener, event objects, form validation, preventing defaults | Create a sign-up form with validation |
| [Day 05](day-05/) | Fetch API & working with JSON data | HTTP requests, fetch(), .then()/.catch(), async/await, parsing JSON | Build a weather app using a public API |

# 🗄️ Module 08 — Databases & Data Thinking

![Level: Intermediate](https://img.shields.io/badge/Level-Intermediate-yellow) ![Days: 3](https://img.shields.io/badge/Days-3-blue)

> Store it. Query it. Understand it.

---

## 🎯 By the End of This Module You Will Be Able To:

1. Explain what a database is, the difference between SQL and NoSQL, and when to use each
2. Write SQL queries — SELECT, INSERT, UPDATE, DELETE — and understand tables, schemas, and relationships
3. Use JOINs to combine data from multiple tables and design normalised database schemas
4. Perform CRUD operations in MongoDB and understand documents, collections, and indexing
5. Design data models for real applications — deciding between embedding and referencing in NoSQL

---

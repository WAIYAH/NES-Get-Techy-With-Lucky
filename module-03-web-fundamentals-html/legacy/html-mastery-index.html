HTML Document Structure

<!DOCTYPE html> <html lang="en"> <head>...</head> <body>...</body> </html>
  • <!DOCTYPE html>: Declares the document type
  • <html>: Root element
  • <head>: Metadata, links, scripts
  • <body>: Visible content
Tip: Always use <!DOCTYPE html> for modern HTML5!

Metadata & Head Elements

  • <title> - Page title (shown in browser tab)
  • <meta charset="UTF-8"> - Character encoding
  • <meta name="viewport"> - Responsive design
  • <link rel="stylesheet"> - External CSS
  • <script> - JavaScript
  • <style> - Internal CSS

Text Elements

  • <h1> to <h6> - Headings
  • <p> - Paragraph
  • <strong> - Bold
  • <em> - Italic
  • <span> - Inline container
  • <br> - Line break
  • <hr> - Horizontal rule
  • <blockquote> - Quoted text
  • <pre> - Preformatted text
  • <code> - Inline code
<h1>Welcome!</h1> <p>This is a paragraph with emphasis.</p> <blockquote>A famous quote</blockquote>

Lists

  • <ul> - Unordered list
  • <ol> - Ordered list
  • <li> - List item
  • <dl> - Description list
  • <dt> - Term
  • <dd> - Description
<ul> <li>HTML</li> <li>CSS</li> </ul> <dl> <dt>HTML</dt> <dd>HyperText Markup Language</dd> </dl>

Links & Media

Links

  • <a href="url">...</a> - Hyperlink
  • target="_blank" - Open in new tab
<a href="https://www.example.com" target="_blank">Visit Example</a>

Images

  • <img src="path" alt="desc"> - Image
  • alt - Alternative text for accessibility
  • width, height - Size
<img src="logo.png" alt="Logo" width="100">

Audio & Video

  • <audio controls><source src="sound.mp3"></audio>
  • <video controls width="320"><source src="movie.mp4"></video>

Tables

TagDescription
<table>Table container
<tr>Table row
<th>Header cell
<td>Data cell
<thead>Table head
<tbody>Table body
<tfoot>Table footer
<caption>Table caption
<table> <caption>Student List</caption> <thead> <tr><th>Name</th><th>Age</th></tr> </thead> <tbody> <tr><td>Lucky</td><td>20</td></tr> </tbody> </table>

Forms

  • <form> - Form container
  • <input type="text|email|password|checkbox|radio|date|number">
  • <label> - Label for input
  • <button> - Button
  • <select> - Dropdown
  • <option> - Dropdown option
  • <textarea> - Multi-line text
  • required, placeholder, value - Common attributes
<form> <label for="name">Name:</label> <input type="text" id="name" name="name" required> <label>Gender: <select name="gender"> <option>Male</option> <option>Female</option> </select> </label> <button type="submit">Submit</button> </form>

Semantic Elements

  • <header> - Page header
  • <nav> - Navigation links
  • <main> - Main content
  • <section> - Section of content
  • <article> - Independent content
  • <aside> - Sidebar
  • <footer> - Page footer
  • <figure>, <figcaption> - Media and caption
  • <mark> - Highlighted text
  • <time> - Date/time
<article> <h2>News</h2> <p>Today is <time datetime="2026-02-28">Feb 28, 2026</time>.</p> </article>

Internal CSS

Internal CSS is written inside the <style> tag in the <head> section. Use classes and IDs for targeting elements.

<style> .highlight { background: #e0f7fa; } #main-title { color: #0077ff; } </style>

JavaScript in HTML

  • <script> - Add JavaScript code
  • Manipulate HTML elements (DOM)
  • Respond to user actions (events)
<script> document.getElementById('demo').innerText = 'Hello, World!'; </script>

Best Practices

  • Use semantic tags for structure
  • Always include alt text for images
  • Keep code indented and readable
  • Validate your HTML
  • Use CSS for styling, not inline style attributes
  • Separate content (HTML), presentation (CSS), and behavior (JS)

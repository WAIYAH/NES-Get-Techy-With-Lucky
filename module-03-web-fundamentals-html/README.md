# 🌐 Module 03 — Web Fundamentals: HTML

![Level: Beginner](https://img.shields.io/badge/Level-Beginner-brightgreen) ![Days: 4](https://img.shields.io/badge/Days-4-blue)

> Build the skeleton of the web. Semantic HTML done right.

---

## 🎯 By the End of This Module You Will Be Able To:

1. Explain what HTML is, how browsers render it, and write a complete HTML document from scratch
2. Use text elements, links, images, and lists to structure real content on a page
3. Build functional tables and forms with proper input types, labels, and buttons
4. Write semantic HTML5 using elements like `<header>`, `<main>`, `<article>`, and `<nav>`
5. Apply accessibility best practices — alt text, ARIA labels, and screen reader-friendly markup

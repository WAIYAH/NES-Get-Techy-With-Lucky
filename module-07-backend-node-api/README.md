# 🖧 Module 07 — Backend Basics: Node.js & APIs

![Level: Intermediate](https://img.shields.io/badge/Level-Intermediate-yellow) ![Days: 4](https://img.shields.io/badge/Days-4-blue)

> Understand the server side. Build your first API.

---

## 🎯 By the End of This Module You Will Be Able To:

1. Explain the client-server model, HTTP methods, status codes, and REST API principles
2. Set up a Node.js project, install packages with npm, and create a basic Express server
3. Define routes, use middleware, handle request parameters, and manage errors gracefully
4. Connect your backend to a database (MongoDB or Firebase) and perform CRUD operations
5. Build and test a complete REST API that a frontend application can consume

---

## 📅 Day-by-Day Breakdown

| Day | Topic | Key Concepts | Exercise |
|-----|-------|-------------|----------|
| [Day 01](day-01/) | How the web works — servers, HTTP & REST APIs | Client-server model, HTTP methods, status codes, REST principles | Explore APIs with Postman/Thunder Client |
| [Day 02](day-02/) | Node.js & Express — setting up a backend | Node runtime, npm, Express server, routes, request/response | Build a "Hello World" API |
| [Day 03](day-03/) | Routes, middleware & handling requests | Route parameters, query strings, middleware chain, error handling | Build a books API with full CRUD |
| [Day 04](day-04/) | Connecting to a database (MongoDB/Firebase intro) | Database connection, CRUD operations, environment configuration | Connect your API to MongoDB |
